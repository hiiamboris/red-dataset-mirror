Generic sort notes
==================

You have a block of objects.

They need to be sorted by a series of keys, some ascending, some descending.

That is not a problem to write a hard-coded SORT/COMPARE function.

But suppose the sort sequence is decided at run-time, perhaps a user's choice to
sort in one of many possible ways ....

.... Well, you could dynamically generate a tailored SORT/COMPARE function (and
     that may be the best solution for pure speed)
     
.... Or you could use something like GENERIC-SORT


Example
=======

Here's some data ....

data: random/secure reduce [
    context [name: "alice" born: 1-jan-2001 health: 88 should-be: 3]
    context [name: "alan" born: 1-jan-2001 health: 200 should-be: 2]
    context [name: "alan" born: 1-jan-2001 health: 45 should-be: 1]
    context [name: "alice" born: 1-jan-1999 health: 100 should-be: 4]
    context [name: "alice" born: 1-jan-1999 health: 500 should-be: 6]
    context [name: "alice" born: 1-jan-1999 health: 299 should-be: 5]
   ]
   
Let's sort it by name (ascending) and date of birth (descending) and health (ascending):

    generic-sort data [name +1 born -1 health +1]
    
Done!
